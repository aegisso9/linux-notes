# Navigasi Linux

## Apa yang Saya Pelajari?

Linux menggunakan filesystem berbentuk tree. Kita perlu memahami cara berpindah antar-directory.

## Command

### `pwd`

Melihat lokasi saat ini.

```bash
pwd
```

### `ls`

Melihat isi directory.

```bash
ls
ls -la
```

### `cd`

Berpindah directory.

```bash
cd /home
cd ..
cd ~
```

## Percobaan

```bash
pwd
ls
cd /tmp
pwd
cd ..
pwd
```
