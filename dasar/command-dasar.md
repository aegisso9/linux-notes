# Command Dasar

| Command | Fungsi |
|---|---|
| `pwd` | Melihat lokasi saat ini |
| `ls` | Melihat isi directory |
| `cd` | Berpindah directory |
| `mkdir` | Membuat directory |
| `touch` | Membuat file |
| `cp` | Menyalin |
| `mv` | Memindahkan / mengganti nama |
| `rm` | Menghapus |
| `cat` | Menampilkan isi file |
| `clear` | Membersihkan terminal |
| `whoami` | Melihat user saat ini |
